# Graphley website

[graphley.ai](https://graphley.ai/) is the Graphley landing page, [Mac download and installation guide](https://graphley.ai/download/), [MCP setup](https://graphley.ai/mcp/), [help](https://graphley.ai/help/) and [privacy](https://graphley.ai/privacy/) pages. The app source is in [protomota/graphley](https://github.com/protomota/graphley).

It is a static site on the house Protomota app-site template, re-skinned with Graphley's "Tide table" design. The production Vercel project is `graphley-site`, deployed from GitHub `main`. There is no build step beyond IndexNow.

## Pages

The HTML pages are generated by `tools/build-site.py` (shared head, header and footer; the Discord, newsletter and More from Protomota tail is `tools/family.html`). Edit the generator and run `python3 tools/build-site.py` rather than editing the pages by hand. The hero's working preview runs on `assets/site.js` with made-up sample data. `tools/render-icons.js` renders the icons from `mark.svg`, and `tools/render-social-card.js` renders `social-card.png` from `tools/social-card.html` (both need Playwright). Nothing in `tools/` except `indexnow.mjs` is deployed.

## Releases

Mac releases are published by `graphley/scripts/release-mac.sh`. It builds, signs, notarizes and staples the DMG, signs the Sparkle feed, copies `Graphley-VERSION.dmg` into `downloads/` and the feed to `/appcast.xml`, then runs:

```sh
tools/set-release.sh VERSION BUILD SHA256 BYTES
```

That points every download link, version, build, size and checksum on the site (download page, home page, the JSON-LD `softwareVersion` and `downloadUrl` on every page, and `llms.txt`) at the new DMG. It checks the staged DMG against the SHA-256 and size, and accepts `pending` for both as a placeholder. With `--publish`, the release script commits the DMG, feed and pages in one commit, pushes `main`, and waits until graphley.ai serves the new installer and feed. Older DMGs stay in `downloads/` so earlier appcast entries keep working.

`vercel.json` serves `/downloads/*` as `application/x-apple-diskimage` attachments, `/appcast.xml` as RSS with a five-minute cache, and redirects `/downloads` to `/download/`.

## Sitemap dates and IndexNow

`tools/indexnow.mjs` runs at the end of every Vercel build. It compares each page in the sitemap with the page that is live, writes `<lastmod>` into the deployed sitemap (today for a page whose words changed, otherwise the date already live), and on a production deploy submits the changed pages to IndexNow so Bing re-reads them within minutes. Preview deploys only print what they would submit. The dates in the committed sitemap are starting values only. Keep `66365049776433ceca35572e03fca658.txt`: IndexNow checks it to confirm the site sent the request.

## Analytics

`assets/analytics.js` loads Google Analytics only after a visitor allows it. The measurement ID is `data-ga` on the script tag in `tools/build-site.py` (`G-PENDING` until the GA4 property exists), then regenerate the pages.

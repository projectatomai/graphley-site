How to install Graphley

  1. Open the disk image.

    Open Graphley-0.1.9.dmg in Downloads. Drag Graphley into Applications, then eject the disk image.

  2. Launch Graphley from Applications.

    If macOS asks for confirmation, choose Open.

  3. Connect Google Analytics.

    Sign in with Google. Graphley asks for read-only access, finds every GA4 property you can read and lets you pick the ones to track.

  4. Add your apps, if you have any.

    Add an App Store Connect API key with access to Sales and Trends. It’s saved in the Keychain. Or connect an agent and let it do the setup: see MCP setup.

Automatic updates. Graphley checks for new versions and installs signed updates for you. You can also choose Check for Updates from the Graphley menu.

Verify your download

In Terminal, run shasum -a 256 ~/Downloads/Graphley-0.1.9.dmg and compare the result with this SHA-256 checksum.

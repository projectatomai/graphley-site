mcp setup

Connect an agent to Graphley.

Graphley’s MCP server runs on your Mac, on the same data as the app. Install Graphley, add it to your agent, and ask for what you want tracked.

On this page How it works Claude Code Codex Claude chat Tools Try it

How it works

The Graphley app runs as an MCP server when your agent starts it with --mcp. It talks over standard input and output, on your Mac only, and reads and writes the same local workspace the app shows. Changes appear in the app right away and are listed under Settings → Agents.

You stay in control. Turn off Let agents make changes to keep agents view only. Saving keys is off unless you turn on Let agents set keys, and even then a key is read from the environment, never typed into a chat.

Claude Code

Add Graphley as a local server for your user or project:

claude mcp add graphley -- /Applications/Graphley.app/Contents/MacOS/Graphley --mcp

Codex

Add this to ~/.codex/config.toml:

[mcp_servers.graphley]
command = "/Applications/Graphley.app/Contents/MacOS/Graphley"
args = ["--mcp"]

Claude chat

In the Claude desktop app, open Settings → Developer → Edit Config and add a graphley entry under mcpServers with the same command and the --mcp argument. Restart Claude.

Tools

ToolWhat it does
get_statusWhich accounts are connected, how many sites, apps and dashboards there are, and when data was last refreshed.
list_sites · list_apps · list_dashboardsWhat Graphley tracks today, with IDs to use in other tools.
query_metricDaily values for any metric, for one site or all of them, optionally by page or platform.
compare_periodsThe last N days against the N days before, per site, with percent change.
discover_ga4_propertiesEvery GA4 property your Google account can read, marked tracked or not.
add_site · update_site · archive_siteTrack a website, change it, or stop tracking it (history is kept).
add_appTrack an App Store app by its Apple ID, linked to its website if you like.
create_dashboard · add_widget · remove_widgetBuild and change dashboards.
refresh_allPull fresh numbers now.
set_app_store_keySave an App Store Connect key to the Keychain. Off unless you allow it.
set_source_key · set_google_service_accountSave a Bing, X, Instagram, OpenTalon or Google service account key to the Keychain. Off unless you allow it.
record_followers · import_historyRecord a follower count for an account with no API, or bring in history from an older tracker.
list_reviewsWritten App Store reviews, with the day each was first seen.
export_backupThe whole workspace and every stored number as one JSON file, for a backup. Keys are never included.
setup_portfolioLoads the maker's own Protomota sites, apps and dashboards in one step, as a worked example.
